### Bucket 2 — TC611 `model_timings` shape (1 failure, `06_integration`)
```
Assertion failed: model_timings entries should identify the model
```
The test asserted that each `model_timings` entry contains a `model` or `modelId`
field. But `getRequestModelTimingStatsDesc()` returns entries typed as
`RequestEndpointTimingStatsEntry`, which uses `endpoint` (not `model`/`modelId`)
as the identifier. The source code is correct; the test assertion was wrong.

**Fix:** Updated assertion in `testcases/06_integration/integration.test.js`
(TC611) to also accept the `endpoint` field:
```js
// Before:
assert(typeof first.model === 'string' || typeof first.modelId === 'string', ...)

// After:
assert(typeof first.endpoint === 'string' || typeof first.model === 'string' || typeof first.modelId === 'string', ...)
```

### Bucket 3 — TC1211 validator collision (1 failure, `12_config_validation`)
```
Assertion failed: PUT with empty composite target {} should be accepted
(got 400: "Invalid model entry for claude.codestrong")
```
**Root cause:** `getLiveModels()` returns the dashboard GET view, which strips
`api_key` and returns 2-element arrays `[model, base_url]`. But
`validateAndNormalizeDashboardModels` calls `isSafeModelArray()` which only
accepts 1-element or 3-element arrays (by design, to prevent ambiguous
round-trips — this is the TC1204 fix). TC1211 passed those 2-element arrays
directly in the PUT body, which the validator correctly rejected on `claude.codestrong`.

The error message was misleading — the rejection was not about the composite
target `{}` at all, but about the malformed models payload surrounding it.

**Fix:** Updated `testcases/12_config_validation/config_validation.test.js`
(TC1211) to normalize the models arrays before PUT, exactly as TC1214 already
does:
- 2-element `[model, url]` (non-empty url) → 3-element `[model, url, '']`
- 2-element `[model, '']` → 1-element `[model]`

This isolates the test to its actual intent (proving `{}` is a valid composite
target config) without polluting it with an invalid models payload.
